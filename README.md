# Fake Store App

A modern e-commerce application built with React and Vite, featuring a responsive design and seamless user experience.

<img width="1907" height="824" alt="image" src="https://github.com/user-attachments/assets/2862b228-2f8a-48e8-995d-6a29c2d8f22b" />

## 🚀 Features

- **Product Browsing:** View a comprehensive list of products.
- **Product Details:** Detailed view for each product including images and descriptions.
- **Responsive Design:** Fully responsive layout using Bootstrap and custom SCSS.
- **Navigation:** Easy-to-use navigation with React Router.
- **SEO Optimized:** Meta tags and titles managed with React Helmet.
- **Offline Support:** User notifications when offline.
- **Interactive UI:** Loading spinners and SweetAlert2 notifications.

## 🛠️ Tech Stack

- **Framework:** [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling:** [Bootstrap](https://getbootstrap.com/) + [Sass](https://sass-lang.com/)
- **Routing:** [React Router](https://reactrouter.com/)
- **HTTP Client:** [Axios](https://axios-http.com/)
- **Notifications:** [SweetAlert2](https://sweetalert2.github.io/)
- **SEO:** [React Helmet](https://github.com/nfl/react-helmet)

## 📦 Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd OnSite-FakeStoreApp
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

## 💻 Usage

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
